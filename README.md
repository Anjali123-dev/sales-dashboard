# sales-dashboard
1. Project Title

Amazon Product Sales Analysis Dashboard | Power BI

Example:

An interactive Power BI dashboard designed to analyze Amazon product sales performance, category trends, YTD sales, and customer reviews.

2. Short Description / Purpose

Example:

This project analyzes Amazon product sales data using Power BI to understand sales trends across months and weeks, compare product categories, and identify top-performing products based on YTD sales and customer reviews. Interactive filters for Product Category and Quarter make it easier to explore the data and identify meaningful business insights.

3. Tech Stack

Example:

Power BI – Dashboard development & data visualization
Power Query – Data cleaning and transformation
DAX – KPI and YTD calculations
Microsoft Excel / CSV – Data source and data preparation

Agar aapne Excel/CSV actually use nahi kiya hai, to usko remove kar dena. GitHub par wahi tools mention karna better hai jo aapne genuinely use kiye hain.

4. Data Source

Example:

Amazon Product Sales Dataset
The dataset contains product-level sales and review information used to analyze sales trends, product categories, YTD performance, and customer reviews.

Agar dataset Kaggle se liya hai, to hum exact Kaggle dataset ka naam/source bhi add kar sakte hain.

5. Features / Highlights

Example:

📊 Sales by Month – Analyze monthly sales trends and identify changes in performance.
📅 Sales by Week – Track weekly sales performance.
🛍️ Sales by Product Category – Compare sales across different product categories.
🏆 Top 5 Products by YTD Sales – Identify products generating the highest year-to-date sales.
⭐ Top 5 Products by YTD Reviews – Identify products with the highest year-to-date review counts.
🔎 Interactive Filters – Explore the dashboard using Product Category and Quarter (Qtr) filters.
📈 Interactive Visualizations – Easily explore sales performance and product-level trends.

# Amazon Product Sales Analysis Dashboard | Power BI

## 📌 Project Overview

This project analyzes Amazon product sales data using Power BI to understand sales trends, product category performance, YTD sales, and customer reviews.

## 🎯 Purpose

The objective of this project is to create an interactive dashboard that helps analyze sales performance and identify top-performing products and categories.

## 🛠️ Tech Stack

- Power BI
- Power Query
- DAX
- Microsoft Excel / CSV

## 📂 Data Source

Amazon Product Sales Dataset containing product-level sales and review information.

## ✨ Features & Highlights

- Sales by Month
- Sales by Week
- Sales by Product Category
- Top 5 Products by YTD Sales
- Top 5 Products by YTD Reviews
- Product Category Filter
- Quarter (Qtr) Filter
- Interactive Power BI Visualizations
